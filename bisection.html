Divide & Conquer Root Finding

By the Intermediate Value Theorem, if f(x_l) · f(x_u) < 0, at least one real root exists in [x_l, x_u]. The bisection method splits the bracket in half at x_r = (x_l + x_u) / 2, cutting uncertainty by exactly 50% each iteration.

📖 Bisection Recipe

  1. Verify Bracket: Confirm f(x_l) · f(x_u) < 0.
  2. Compute Midpoint: x_r = (x_l + x_u) / 2.
  3. Sign Test:
    • If f(x_l) · f(x_r) < 0, root in left half → x_u = x_r.
    • If f(x_l) · f(x_r) > 0, root in right half → x_l = x_r.
    • If f(x_l) · f(x_r) = 0, x_r is exact root!
  4. Check Error: ε_a = |(x_r - x_r^old) / x_r| · 100%.
