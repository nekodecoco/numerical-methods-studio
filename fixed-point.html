📖 Fixed-Point Recipe

  1. Rearrange: Transform f(x) = 0 into x = g(x).
  2. Check Derivative: Evaluate |g'(x)|. If < 1, convergence is guaranteed locally!
  3. Iterate: Evaluate x_{i+1} = g(x_i).
  4. Staircase Step:
    • Move vertically to y = g(x_i).
    • Move horizontally to y = x to set x_{i+1}.
  5. Check Error: ε_a = |(x_{i+1} - x_i) / x_{i+1}| · 100%.
